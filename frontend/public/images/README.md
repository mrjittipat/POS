|---------|----------|-----------|--------|
| (รอระบุ) | - | - | ⬜ ยังไม่ใส่ |

## รูปแบบไฟละที่รองรับ
- `.png` — สำหรับโลโก้, ไอคอน, รูปที่มีพื้นหลังโปร่งใส
- `.jpg` / `.jpeg` — สำหรับรูปสินค้า, รูปประกอบ
- `.svg` — สำหรับไอคอน, โลโก้ที่ต้องขยายได้
- `.webp` — สำหรับรูปสินค้า (ขนาดเล็กกว่า)

## วิธีเรียกใช้ในโค้ด

```tsx
// สำหรับรูปที่อยู่ใน public/images/
<img src="/images/logo.png" alt="POS Logo" />

// หรือใช้กับ CSS background
<div style={{ backgroundImage: 'url(/images/bg.png)' }}></div>
```
